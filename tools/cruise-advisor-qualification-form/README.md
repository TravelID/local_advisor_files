# Cruise Advisor Qualification Form — v1.0

**A practical cruise consultation form for travel advisors.**

Use this browser-based form during a client conversation to capture cruise preferences and prepare the next steps for researching and quoting an itinerary.

## What it covers

- Client and travel details, including timing and budget
- Cruise style, destinations and preferred cruise lines
- Traveller type, cabin category and cabin-location priorities
- Onboard experiences, inclusions and shore activities
- Flights, hotels, transfers and other travel arrangements
- Documentation and special requirements
- Advisor notes, follow-up details and booking readiness

## Download and use

**[Download Cruise Advisor Qualification Form v1.0](Cruise_Advisor_Qualification_Form_v1.0.html)**

1. Open the link above and use GitHub's **Download raw file** option (or choose **Raw** and save the file).
2. Save the HTML file to your computer.
3. Open it in Chrome, Edge or another modern browser.
4. Complete the form during the consultation.
5. Select **Print / Save PDF** for a printable copy, or **Export to Excel** for a CSV file.

The file is designed to run locally. No installation, login or database is required. The form does not automatically save entries; if you close the page, unsaved responses may be lost.

**Printing:** The layout was adjusted and tested to fit the full blank form, including Advisor Notes / Next Steps, on one A4 page using Chromium. Browser settings, entered text length and printer scaling can affect pagination. Check the print preview before saving or printing.

**Excel export:** The exported file is CSV, not an Excel `.xlsx` workbook.

## Privacy and professional use

This tool supports consultation and administration; it does not replace agency procedures or independent checks of fares, availability, travel requirements or booking details.

Handle completed PDFs and CSV downloads as potentially confidential client records. Only enter personal information when its handling meets your organisation's privacy and security requirements.
